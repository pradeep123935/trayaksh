# Trayokas
## Property Inspection & Consulting

## Requirements

1. Users can book an inspection by selecting a date and time slot.
2. Users receive an email confirmation after booking an inspection.
3. Bookings are saved in the database.

## Non-Functional Requirements

1. The site is primarily static.
2. The site is optimized for single sign-on (SSO).
3. The site is optimized for search engine visibility.
4. The page is responsive across devices.
5. The site provides high availability.
